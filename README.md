# OnlyFans API documentation (OFMAPI)

The documentation for the OFMAPI OnlyFans API lives at
**https://ofmapi.com/docs**: quickstart, authentication, every REST
endpoint in an interactive reference, webhooks, rate limits, the hosted MCP
server for Claude and ChatGPT, and client generation guides for Python,
TypeScript, and Go. The docs are part of the main web application, so their
source is not mirrored here.

Use this repository for documentation issues and requests: a page that is
unclear, a missing example, a parameter that does not match the API. Open
an issue and link the page.

The old `docs.ofmapi.com` links redirect to the pages above.

## What OFMAPI is

An independent, unofficial OnlyFans API for agencies and developers: typed
REST endpoints, signed webhooks, and a hosted MCP server (174 tools). Free
during the public Beta; documented usage limits apply. There is no official
OnlyFans developer API.
