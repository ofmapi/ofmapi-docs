# OFMAPI documentation

The OFMAPI docs live at **https://ofmapi.com/docs**. They are part of the
main web application, so their source is not mirrored here.

Use this repository for documentation issues and requests: a page that is
unclear, a missing example, a parameter that does not match the API. Open
an issue and link the page.

## Where things are

- Docs home: https://ofmapi.com/docs
- Quickstart: https://ofmapi.com/docs/quickstart
- Interactive API reference (no login): https://ofmapi.com/docs/api
- OpenAPI 3.1 spec: https://ofmapi.com/openapi.json
- MCP setup for Claude, ChatGPT, Cursor, and VS Code:
  https://ofmapi.com/docs/integrations/mcp
- Webhooks: https://ofmapi.com/docs/webhooks
- FAQ: https://ofmapi.com/docs/faq
- Status: https://ofmapi.com/status

The old `docs.ofmapi.com` links redirect to the pages above.
